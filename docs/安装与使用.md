# 竹叶输入法 安装与使用指南

## 文档信息

- 版本：v0.1.0
- 状态：发布就绪（M5）
- 日期：2026-09-21
- 关联文档：README.md、需求规格说明书.md、方案设计.md、验收标准.md、architecture.md、licenses.md、CHANGELOG.md

## 1. 适用范围

- Windows 10/11 x64
- 现代 TSF 应用：记事本、浏览器、IDE、Office 等
- 提供全拼中文输入、候选区中英译文、译文层切换与本地用户词学习
- 默认完全离线，不收集输入内容

## 2. 构建环境要求（开发者）

在源码机器上安装：

- Windows 10/11 x64
- Rust 1.98.1+（仓库由 `rust-toolchain.toml` 固定版本）
- 目标工具链 `x86_64-pc-windows-msvc`
- Git

测试机若只使用便携包，不需要安装 Rust。

## 3. 构建

```powershell
cargo build --workspace
cargo fmt --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

发布/安装前构建 release DLL：

```powershell
cargo build -p zhu-ye-ime --release
```

构建 v2 词典包（默认输出 `data/artifacts/seed.zyct`，该目录不进入 git）：

```powershell
cargo run -p zhu-ye-dict -- build
```

## 4. 安装

1. 在源码根目录打开 PowerShell。
2. 以管理员身份运行安装脚本：

```powershell
.\scripts\install.ps1
```

脚本会先构建 release DLL，校验 DLL 导出，复制到 `C:\Program Files\ai-zhu-ye-ime\tsf\zhu-ye-ime.dll`，然后写入 TSF 注册表项并校验结果。

脚本同时把 v2 词典复制到同一目录 `dictionary.zyct`：优先使用 `data/artifacts/real.zyct` 真实词库，不存在时使用自建演示种子；两者都没有时自动构建演示种子。TSF 运行时优先加载 DLL 同目录词典。

常用参数：

```powershell
# 已构建过 DLL，跳过构建
.\scripts\install.ps1 -SkipBuild

# 指定安装目录
.\scripts\install.ps1 -InstallDir C:\Tools\ai-zhu-ye-ime\tsf

# 指定词典文件
.\scripts\install.ps1 -DictionaryPath .\data\artifacts\real.zyct
```

重复安装安全：每次安装先清理旧注册再重建，不会产生重复路径。如果 DLL 正被进程占用，脚本会提示并停止，请关闭正在使用输入法的应用后重试。

## 5. 启用与切换

安装完成后进入系统设置：

```text
设置 -> 时间和语言 -> 语言和区域 -> 中文（简体，中国）-> 键盘
```

确认“竹叶输入法”已列出并启用。日常输入时使用系统输入法切换键切换：

- `Win + Space`
- 或 `Ctrl + Shift`（取决于系统设置）

安装后无需重启系统；新打开的应用即可使用竹叶输入法。正在运行的应用可能需要重启一次才会加载新 DLL。

## 6. 基本使用

### 6.1 中文输入

输入全拼字母串，候选窗显示中文候选；拼音切分支持歧义路径，如 `xian` 同时支持“西安”与“先”。

| 按键 | 行为 |
| --- | --- |
| `Shift` | 中英模式切换 |
| `Tab` | 中文候选层 <-> 译文层 |
| `Space` | 上屏第一候选 |
| `1` - `9` | 上屏对应候选项 |
| `-` / `=`（`Shift`+`=` 即 `+`） | 上翻页 / 下翻页（T-033） |
| `Enter` | 上屏拼音原文 |
| `Esc` | 取消本次输入 |

### 6.2 译文

中文候选行右侧以弱化样式显示英文译文。按 `Tab` 进入译文层，候选列表切换为英文译文；按 `1` 等数字键上屏译文，上屏后自动返回中文候选层。

没有译文的词不会强制进入译文层，也不会出现空白页。

### 6.3 用户词

选择过的中文词会记录到本地用户词库，并在后续排序中提升权重。删除与重置通过 CLI 完成：

```powershell
cargo run -p zhu-ye-cli -- user list
cargo run -p zhu-ye-cli -- user delete 你好 nihao
cargo run -p zhu-ye-cli -- user reset
```

用户词库路径：`%APPDATA%\ai-zhu-ye-ime\user_words.json`。文件损坏时输入法会自动备份为 `.bak` 并重建空库，不会影响静态词典。

### 6.4 CLI 诊断

```powershell
# 环境与模块自检
cargo run -p zhu-ye-cli -- self-check

# 候选演示（无词典文件时回退内存演示词典）
cargo run -p zhu-ye-cli -- demo nihao

# 词典检查与完整性校验
cargo run -p zhu-ye-dict -- inspect data/artifacts/seed.zyct
cargo run -p zhu-ye-dict -- verify data/artifacts/seed.zyct

# 词典查询与译文反查
cargo run -p zhu-ye-cli -- dict data/artifacts/seed.zyct nihao
cargo run -p zhu-ye-cli -- dict data/artifacts/seed.zyct -r hello
# 候选排序验证（真实词典 + 可选前词上下文 bigram）
cargo run -p zhu-ye-cli -- rank data/artifacts/real.zyct de
cargo run -p zhu-ye-cli -- rank data/artifacts/real.zyct de 我们

# 性能基准（正式验收使用 release）
cargo run --release -p zhu-ye-cli -- bench
.\scripts\bench.ps1 -Release

# 主机侧端到端回归（核心输入闭环，有真实词典时追加 smoke）
.\scripts\e2e.ps1
.\scripts\e2e.ps1 -Release
```

## 7. 隐私与本地数据

- 默认配置下不发起任何网络请求，运行时 AI 能力未启用
- 输入内容只在本机处理，用户词库仅写本地用户目录
- 日志仅写入本地，不包含自动上传行为
- 后续 AI 能力必须显式开启，且结果带来源标识

## 8. 升级

1. 拉取新版本代码并构建：

```powershell
cargo build -p zhu-ye-ime --release
```

2. 以管理员身份重新执行 `.\scripts\install.ps1 -SkipBuild`。
3. 重启正在使用输入法的应用，使其加载新 DLL。


安装器会用新版本词典覆盖安装目录中的 `dictionary.zyct`，无需手动处理。升级不删除用户词库。版本与功能变更见 CHANGELOG.md。
## 9. 卸载

以管理员身份运行：

```powershell
.\scripts\uninstall.ps1
```

脚本删除 TSF 与 CLSID 注册表树、安装目录中的 DLL，目录为空时一并移除，并校验注册表无残留。重复执行安全。

如果 DLL 被占用，会提示关闭相关应用后重试。用户词库与日志位于 `%APPDATA%\ai-zhu-ye-ime`，卸载脚本不会删除；确认不再需要时手动删除该目录。

安装目录中的 `dictionary.zyct` 词典与旧版 `seed.zyct` 会随卸载一并清理。

## 10. 便携包测试

生成便携测试包（无需目标机器安装 Rust）：

```powershell
.\scripts\package-portable.ps1
```

产物位于 `target\portable\ai-zhu-ye-ime-<version>-test.zip`，包含 release DLL、v2 词典（有真实词库时优先打包）与安装/卸载/校验脚本。在测试机解压后：

```powershell
.\scripts\install.ps1 -SkipBuild
.\scripts\uninstall.ps1
```

建议先在虚拟机或系统还原点保护下测试安装/卸载闭环。

## 11. 故障排查

| 现象 | 处理 |
| --- | --- |
| 安装报“需要管理员权限” | 使用管理员身份重新打开 PowerShell |
| 安装报 DLL 被占用 | 关闭输入法相关应用后重试 |
| 输入法不在系统列表 | 检查“键盘”设置是否已启用；重新运行 install.ps1 |
| 切到竹叶输入法后无候选 | 确认已通过系统切换键激活；重启应用后再试 |
| 候选窗错位/模糊 | 确认系统缩放为受支持的 DPI；重启应用 |
| 用户词异常 | 检查 `%APPDATA%\ai-zhu-ye-ime`，必要时删除或重置用户词库 |
| 性能异常 | 运行 `.\scripts\bench.ps1 -Release`，对照验收标准第 3 节 |

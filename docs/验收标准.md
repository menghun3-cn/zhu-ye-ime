# 竹叶输入法 验收标准

## 文档信息

- 版本：v0.1.0
- 状态：已评审
- 日期：2026-09-18
- 依据：需求规格说明书 v0.1.0、方案设计 v0.1.0

## 1. 验收原则

1. 所有验收必须可执行、可复现：能用命令、脚本或固定操作步骤验证
2. 功能验收与需求编号一一对应
3. 性能验收在验收机（Windows 10/11 x64，8GB 内存以上）上进行，前 3 次后取平均值
4. 未达到标准的关键项不得标记任务完成，只能标记阻塞或进行中
5. 周期任务到期后必须登记观察结论，不能直接删除

## 2. 功能验收

### FR-001 全拼中文输入

| 检查项 | 操作 | 期望结果 |
| --- | --- | --- |
| 基础拼音 | 在记事本输入 `nihao` | 出现中文候选，可上屏"你好" |
| 音节切分 | 输入 `xian` | 同时支持"西安"与"先"类切分 |
| 数字选择 | 输入拼音后按 2 | 第 2 候选上屏 |
| 翻页 | 按 `.` | 显示下一页候选 |
| 清空 | 按 Esc | 输入状态清空，候选消失 |
| 前缀候选（T-029） | 输入 `nih`（尚未完整切分） | 出现候选：前缀补全词优先（如"你好"），随后完成音节候选（如"你/泥/拟"），可数字选择，选中后残留拼音丢弃 |
| 无候选页眉条（T-031） | 输入 `z`（无词前缀） | 候选框仍显示，只含拼音组合与提示的页眉条；上屏/取消后隐藏 |

## 3. 性能验收

| 指标 | 验收值 | 目标值 | 测量方式 |
| --- | --- | --- | --- |
| 候选刷新延迟 | <= 30ms | <= 15ms | CLI bench / 宿主内计时 |
| 词典常驻内存 | <= 100MB | <= 50MB | mmap 数据集大小 + 进程占用 |
| 冷启动首次出候选 | <= 300ms | <= 200ms | 注册后首次输入计时 |
| 常驻后台进程 | 0 个 | 0 个 | 任务管理器检查 |
| 在线关闭时网络请求 | 0 次 | 0 次 | 抓包/网络风暴工具 |

## 6. 周期任务验收

T-017 为每两周一次的观察任务，验收规则：

- 到期后执行一次"日常输入 + 性能 + 稳定性"检查
- 将结果追加到 todos-done.md，不删除 T-017 任务本体
- 发现问题时创建新任务，并标记当前观察轮结论为"需处理"

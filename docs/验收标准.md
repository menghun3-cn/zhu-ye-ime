## 1. 验收原则

1. 所有验收必须可执行、可复现：能用命令、脚本或固定操作步骤验证
2. 功能验收与需求编号一一对应
3. 性能验收在验收机（Windows 10/11 x64，8GB 内存以上）上进行，前 3 次后取平均值
4. 未达到标准的关键项不得标记任务完成，只能标记阻塞或进行中
5. 周期任务到期后必须登记观察结论，不能直接删除

### FR-018 常用词覆盖与排序优化

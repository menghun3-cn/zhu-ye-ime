# 命中率评测集与基准（T-057）

> 分类：设计 ｜ 状态：进行中 ｜ 关联任务：T-057（用户四项增强第①项） ｜ 关联 FR：场景2/场景5

## 1. 目的

输入法的核心体验是"想打的字词在多快的位置出现"。此前各里程碑（T-044 排序、T-055 整句）
都靠单点用例（`rank` / host-e2e 断言）验证，没有**规模化、可复现、可对比**的命中率口径；
后续增强（上下文联想、数字/符号/emoji 候选、混输、领域自动等）也缺少对照基线。

本任务建立第一版确定性评测基础设施：一份入库的评测样本集 + 两条评测命令 +
首轮真实词典（`data/artifacts/real.zyct`）基准数字，作为后续所有排序类改动的回归基线。

## 2. 评测口径（决定）

| 指标 | 定义 | 判定 |
| --- | --- | --- |
| Top1 | 输入样本拼音串，候选排序后首候选 == 目标词 | `ranked[0].text == 词` |
| Top3 | 前 3 位候选包含目标词 | `ranked[..3]` 含 `词` |
| 整句 | 输入整句拼音串，首候选 == 期望句 | `ranked[0].text == 期望句` |

- 与"组内最常用词"口径不同：目标词是**用户想打的词**（样本身份），不是同音组最高频词，
  因此 Top1 反映真实打字命中（想打"识别"而首候选是"失去"即记为 MISS）。
- 上下文：词样本**无前词**（零上下文冷启动，`RankingContext::new(None, …)`）；
  整句样本天然携带句子内部上下文（bigram 参与评分）。
- 确定性与隔离：排序模型直接用 `StaticRankingModel`（与 CLI `rank`、引擎同权重，
  见 `crates/zhu-ye-cli/src/main.rs::rank_command` 复用管线）；用户词典置空，保证可复现。

## 3. 样本集（入库 `data/eval/`）

### 3.1 词样本 `words-top2000.tsv`（生成）

- 来源与生成器：`zhu-ye-dict eval-set <CC-CEDICT> <词频> <out.tsv> [--top N]`
  1. 解析 CEDICT（`parse_cedict_line`），保留**纯 CJK 词**且**音节数 == 字数**
     （与 `import` 同清洗口径；多音词取 CEDICT 首读）；
    拼音经 `normalize_pinyin` 输出无调连拼（`nǚ`→`nv`、删数字调、去界符）。
  2. 与 wordfreq 词频表（`load_frequency_map`）取交集，按词频降序取前 N（默认 2000）。
  3. 输出 TSV：`词<TAB>拼音<TAB>词频`，UTF-8 无 BOM、LF。
- 入库理由：样本只含词形、拼音、词频三个标量，千行级体积，入库保证任何环境可复现同一评测。
- 完整性：CEDICT 缺注音的 wordfreq 词被排除（如纯英文/数字词），交集规模在生成时打印。

### 3.2 整句样本 `sentences-100.tsv`（人工）

- 100 句日常常见句（含此前里程碑用例：我想明天去北京 等），
  格式 `期望句<TAB>拼音串`（拼音串人工给出、无调连拼），覆盖常用单双字词与常见搭配。
- 收录规则：日常口语/办公高频句型；不含标点（评测只覆盖拼音路径）。

## 4. 评测命令与输出

`zhu-ye-cli eval <词典> <词样本.tsv> [整句样本.tsv] [--out-miss <文件>]`

- 词样本统计：样本数、Top1 命中率、Top3 命中率；
  按词频分档（≥1M / ≥100k / ≥10k / 其余）报告各档 Top1，暴露低频段退化。
- 整句统计：样本数、首候选命中率。
- MISS 清单：Top1 未命中的样本（`词\t拼音\t实际首候选`）写入 `--out-miss`（默认
  `eval-miss.tsv`），便于人工审查改进方向。
- 可复现：同词典两次执行输出完全一致（确定性输入 → 确定性输出）。

## 5. 基准回填（首轮）

以 `data/artifacts/real.zyct`（2026-09-30 重建，含 T-056 多音补丁，SHA-256
`429ab282…`）跑首轮。评测命令：
`zhu-ye-cli eval data/artifacts/real.zyct data/eval/words-top2000.tsv data/eval/sentences-100.tsv --out-miss <文件>`
两次运行输出与 MISS 文件 MD5 完全一致（确定性已验证）。

| 指标 | 数字 | 说明 |
| --- | --- | --- |
| 词样本数 | 2000 | `eval-set --top 2000`，词频 3,957,141（的）~ 2,687（小组） |
| Top1 | **84.7%** | 无上下文冷启动，目标词==首候选 |
| Top3 | **97.2%** | 目标词在前 3 位 |
| 整句首候选命中 | **21.0%** | 100 句人工样本；beam 对任意句 Top1 偏弱（多为同音字/词选择差异，如 迟→吃、晚→玩），见 MISS 抽样 |
| 档位 ≥1,000,000 | n=6，Top1=100.0% | |
| 档位 ≥100,000 | n=78，Top1=91.0% | |
| 档位 ≥10,000 | n=553，Top1=87.9% | |
| 档位 <10,000 | n=1363，Top1=83.0% | 低频段退化明显，联想/排序增强的主战场 |

结论：Top3 已达 97%，Top1 84.7% 接近但未达 85%+ 期望；整句 21% 暴露 beam
对任意句的首句命中短板。这两个数字即后续增强（上下文联想、数字/符号候选、混输）
的对照基准——任何改动不得使 Top1/Top3 相对本表回退。

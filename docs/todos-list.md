# 竹叶输入法 任务清单（todos-list）

## 维护规则

- 状态三态：`待办` / `进行中` / `已完成`
- 编号规则：`T-xxx` 全局唯一，增量递增；当前已用至 `T-035`
- FR 关联：任务必须关联需求规格说明书中的需求编号
- 周期任务：到期后登记观察结论并追加到 todos-done，不迁移、不删除任务本体
- 提交前校验：任务状态与实现进度一致，未完成不得标记已完成

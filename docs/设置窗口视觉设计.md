## 1. 设计目标与原则

本设计是**设置窗口的视觉改版**（`zhu-ye-settings.exe`，原生 Win32 + GDI 自绘）：只换"面容"，不动骨骼。

1. **品牌克制融合**：竹叶品牌以"颜色系统 + 一个品牌位"进入工具窗口，其余全部安静；不做吉祥物、不做背景花纹、不做宣传腔
2. **系统第一性**：字体、键盘焦点、高对比度、深浅色跟随系统；视觉只改变绘制面，不改变交互机制与条目行为
3. **GDI 能力边界**：全部面容锁定在 GDI 可表达范围（实色、细线、圆角矩形、ClearType 文字），不引入渐变、投影、半透明、动画（§9）
4. **与候选窗并存**：设置窗绿系与候选窗蓝系并存（官网已有"蓝候选窗嵌在竹叶品牌页面"先例）；候选窗配色不随本次改动（S-15 联动义务不受触发）
5. **诚实呈现**：占位条目保持"可见 + 规划中标记"，不灰显隐藏；深色按钮的墨字配色有对比度依据（§4.3），不为了美观牺牲可读性

**现状**（T-073 起、T-125 排版规范化后）：Windows 原生中性风——白底 + `#F3F3F3` 导航列 + `#E1EEFB` 淡蓝选中 + `#1E88E5` 强调；深色 `#1F1F1F` 底。视觉上"任何设置框都长这样"。

**本次改动面（仅视觉语言）**：

| 维度 | 改动 | 不动 |
| --- | --- | --- |
| 颜色 | 全部令牌换为竹叶家族（§4） | 深浅色跟随系统的口径（D-30）、高对比走系统色 |
| 字体 | 同栈内调整字重/字距层级（§5） | 字体族（系统 UI 字体）、字号体系（16/13/24，T-125 验收值） |
| 布局 | 导航列顶新增品牌块（§6.2） | 窗口 880×700、导航 200、行高 76、标题区 80、内边距 26 |

| 信息架构 | 无 | 三页条目、导航文案、条目顺序（FR-039~045 + T-088 五项增强已定稿） |

## 3. 视觉方向：竹纸上的绿

**概念**：设置窗口是"竹纸上一页安静的目录"——底色是竹纸白，墨是墨绿黑，叶是竹叶青；竹节棕只在品牌块下划一道细线，新芽黄绿只出现在"规划中"记号。**唯一记忆点：导航列顶部的品牌块**（竹叶图形 + 「竹叶输入法」字标 + 竹节棕细线），由此确立"绿=身份"——颜色承担身份，图形只出现一次。

与官网的关系：令牌同源（同一支竹叶家族），但设置窗口是高频工具界面，不做官网的吉祥物、渐变、动效；官网的丰富表达与窗口的克制是同一品牌的两档音量。

### 模板味规避（对照自查）

- 底色是竹纸微绿 `#F7F9F4`，不是暖奶油；深色是墨绿黑 `#1F2822`，不是 `#0B0B0B`/`#111` 配霓虹绿
- 无 ALL-CAPS 眉题、无"·"串接的元信息、无「词 — 破折号」标签、无卡片阴影套件、无按钮箭头尾缀
- 等宽字体只用于真实路径/版本/词条数（有数据语义）；"规划中"标签沿用官网语义，不用数字序号

## 10. 可访问性口径

- 正文/描述/标签/按钮文字全部 ≥4.5:1（实测表见 §4）；深色按钮墨字设计即为达标（白字 2.3:1 被否决）
- 键盘焦点：绘制 2px `--leaf` 焦点环（`WM_SETFOCUS`/绘制态），TAB 顺序与视觉顺序一致
- 状态不只靠颜色：`--ok`/`--warn` 状态行同时给出文字（"已注册/正常/异常"）
- 高对比度模式：按 D-30 既有口径完全跟随系统配色，不叠加品牌色
- 深浅两态分别按独立色对校验（不假定浅色值在深色下成立）

## 1. 设计目标与原则

官网回答四个问题，按优先级排序：

1. **这是什么**：竹叶输入法——Windows 上的轻量拼音输入法，候选行内附英文译文
2. **独特在哪**：输入中文时候选旁就有译文，`Tab` 切换译文层可直接上屏英文；默认全离线
3. **诚实到什么程度**：只宣称已实现并经测试/验收的能力；规划项在"路线图"区块显式标注
4. **怎么获取**：Windows 10/11 x64，当前内测阶段，入口如实呈现

原则（沿用仓库既有文化）：

- **自研可控**：零构建、零第三方资源；字体走系统栈；图标、logo、吉祥物、插图全部自绘 SVG
- **默认离线**：站点本身无任何第三方脚本/统计/字体 CDN；`file://` 直开可用（NFR-012）
- **内容诚实**：文案与已验收能力清单逐条对应（NFR-011），改产品能力时站点同步改
- **借鉴留痕**：参考青简官网的信息架构与页面组织，不采用其技术栈与视觉（见 §3、§12）

## 2. 技术选型与理由

**决策（D-67）：零构建手写静态站**——`site/` 下纯 HTML + 一份共享 CSS + 零 JS。

| 候选 | 结论 | 理由 |
| --- | --- | --- |
| 零构建静态站（采纳） | ✅ | 5 个低频更新的页面；无工具链、无依赖、任何托管/file:// 直开；符合"自研可控"；页面增删靠复制式共享布局（S-14）+ 内链自检兜底 |
| SvelteKit + adapter-static（青简同款） | ❌ | 须引入 Node/pnpm 工具链与构建步骤，与仓库 Rust/PowerShell/git 工作流冲突（AGENTS.md 第 8 节）；为 5 页静态内容引入框架，第一性原理不成立 |
| Rust 静态生成器（cargo 现成） | ❌ | 本期页面少、内容静态，生成器收益为零；当站点演进到"文档全量发布 + 自动目录"时再评估（演进记录于 S-13） |
| mdbook/Docusaurus/VitePress | ❌ | 文档框架气质不匹配产品官网；引入 Node 或 Rust 依赖 |

**零 JS 决策（S-16）**：整站不使用任何脚本文件；动效只用 CSS（`@media (prefers-reduced-motion)` 可关）；
唯一的 `<script>` 是首页 JSON-LD 结构化数据（数据声明，非逻辑）。移动端导航以换行收起实现，
不需要汉堡菜单（仅 5 个链接）。

## 3. 站点信息架构

### 3.1 页面与导航

```
site/
  index.html          首页（hero / 特性 / 候选窗示例 / 路线图）
  docs/index.html     文档页（安装与使用提炼，锚点目录）
  download/index.html 下载页（发布状态 + 安装说明）
  privacy/index.html  隐私页（零网络 / 本机处理声明）
  about/index.html    关于页（简介 / 技术栈 / 许可 / 链接）
  404.html            未找到（吉祥物 404 姿态）
  assets/
    css/site.css      全站样式（唯一 CSS）
    logo.svg          品牌主标（图形 + 字标组合）
    logo-mark.svg     logo 图标变体（favicon 用）
    favicon.svg       favicon
    mascot-hero.svg   吉祥物·hero 站姿
    mascot-point.svg  吉祥物·引导姿态（文档/下载页）
    mascot-404.svg    吉祥物·探头姿态（404）
    cand-window.svg   候选窗示例插图（真实配置快照，S-15）
  llms.txt           AI 检索入口（llmstxt.org v2，FR-058/S-18）
  agents.txt         面向 AI 代理的站点导读（本站格式，FR-058/S-18）
  robots.txt         爬虫允许声明（FR-058）
  sitemap.xml        页面集合一致性（FR-058，部署域名后更新）
  README.md           维护与部署说明
```

各页共享 header（品牌字标 + 4 个站内链接 + GitHub 链接）与 footer（品牌句 + 站点/社区两列 +
版本状态行 + 版权行）。当前页 `aria-current="page"` 高亮。

### 3.2 URL 与链接契约

- 全部站内链接用**相对路径**：`site/docs/` 下链接资产用 `../assets/...`，页间用 `../docs/index.html`、
  `../download/index.html` 等
- **页面链接必须显式写 `index.html`**（如 `./docs/index.html`、`../index.html`）：Chromium 系浏览器
  的 `file://` 对以 `/` 结尾的目录 URL 渲染目录列表而非 `index.html`，显式文件名才能保证
  file:// 直开与 GitHub Pages 两种环境行为一致；sitemap.xml 仍用目录形式 URL（部署环境语义）
- 禁止站内绝对 URL（Pages 以项目仓库发布时挂 `/repo/` 前缀，相对路径才能自适应）
- 站外链接（GitHub 等）用完整 `https://`，新窗口打开
- **契约由 `scripts/check-site-links.ps1` 强制**：解析所有 HTML 的 `href`/`src`，站内相对引用必须
  命中真实文件，外部链接仅报告不校验

## 4. 视觉体系（令牌）

### 4.1 设计概念

**竹纸与竹叶**：页面底色为微绿的竹纸白，主文字为墨绿黑，交互与品牌色为竹叶青，点缀为竹节棕
与少量新芽黄绿。整体气质"清瘦、安静"，与青简（暖白底 + teal 绿 + 宋体字标 + 竹影动画）拉开
距离：竹叶用**无衬线字标 + 图形 logo + 吉祥物**，不做竹影背景动画，不用宋体做字标（S-13 下的
视觉差异化，见 §12 借鉴记录）。

### 4.2 配色令牌

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#F7F9F4` | 页面底色（竹纸白，微绿，非暖奶油） |
| `--ink` | `#22302A` | 主文字（墨绿黑） |
| `--leaf` | `#3D7A4E` | 品牌竹叶青：链接、按钮、强调 |
| `--leaf-deep` | `#2C5A3B` | 墨绿：页脚底色、hover、深色块 |
| `--sprout` | `#9AC36A` | 新芽黄绿：小面积点缀（数据徽标等），禁用大面积 |
| `--bark` | `#9C7B4F` | 竹节棕：分隔细线、装饰笔画，少量 |
| `--muted` | `#66736A` | 次要文字（译文、页脚小字） |
| `--line` | `#E2E8DE` | 细分隔线 |
| `--panel` | `#FFFFFF` | 候选窗示例/代码块底色 |
| `--tag-bg` | `#EEF2EC` | "规划中"标签底色 |

候选窗示例内的颜色**锁定产品真实配置**（T-030/032/037/043 验收值）：面板 `#FFF`、边框与主词
`#1E88E5`、选中行底 `#E6F2FE`、选中文字 `#D32F2F`、序号/译文 `#999`、选中块贴边（S-15）。

### 4.3 字体

| 角色 | 栈 |
| --- | --- |
| 正文 | `-apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", sans-serif` |
| 字标 | 同正文栈，`700` 字重 + 适度字距；拉丁名 `ZHUYE` 小字号、`letter-spacing: .18em`、次要色 |
| 代码/键位 | `"Cascadia Code", Consolas, "Courier New", monospace` |

不用网络字体（NFR-012）；行宽 ≤ 80 字符；正文 `line-height: 1.75`，标题 `1.3`。

### 4.4 布局（ASCII 线框）

```
首页
┌────────────────────────────────────────────┐
│ header: [竹叶 ZHUYE]  首页 文档 下载 隐私 关于 ⌂GH │
├────────────────────────────────────────────┤
│ hero 左: 大标题(2行) 一句话  [下载体验][看文档]   │
│ hero 右: 候选窗示例插图 + 吉祥物               │
├────────────────────────────────────────────┤
│ 特性：4 块 × 2 列（细竹节线分隔，无卡片阴影）     │
├────────────────────────────────────────────┤
│ 候选窗示例放大 + 一句解说（插图复用 hero）       │
├────────────────────────────────────────────┤
│ 路线图（"规划中"标签，与已实现严格区分）          │
├────────────────────────────────────────────┤
│ footer: 品牌句 │ 站点·社区 │ 版本状态 © 2026    │
└────────────────────────────────────────────┘
```

- 正文列宽 `max-width: 1040px`，居中；移动端（<720px）单列、hero 图下移
- 特性区**不用等尺寸圆角卡片 + 灰阴影**（规避 AI 模板味），用左对齐图标 + 标题 + 一段说明 +
  `--line` 细分隔；不引入数字序号（内容非序列）
- 首屏一次编排时刻：hero 竹叶图形从底部轻微上浮一次（CSS 动画 700ms），`prefers-reduced-motion`
  时完全静止；无滚动揭示、无 hover 弹跳

### 5.2 文档页（FR-053）

单页 + 锚点目录（`#install`、`#enable`、`#keys`、`#translation`、`#userwords`、`#uninstall`、
`#troubleshoot`），内容提炼自 `docs/安装与使用.md`：系统要求、发行包安装、启用与切换、
键位表、译文用法、用户词说明、卸载、故障排查表。文末链接"完整开发文档在仓库 docs/ 与
README"。规划能力一律不出现。

### 5.3 下载页（FR-054）

- 系统要求卡：Windows 10/11 x64；现代 TSF 应用
- **以安装包为主**（D-69）：页面主体是"发行包"形态与获取入口，下载内容一律为
  **GitHub Releases 资产直链**（站点不托管安装包）
- **发布状态如实框**：当前为**内测阶段**，暂无公开发行版；入口 = GitHub Releases 页
  （查看后续发布）+ 源码构建（README 快速开始）；不得出现无对应的下载按钮（NFR-011）
- **发行包形态表**（当前真实 + 计划如实区分）：

  | 形态 | 状态 | 说明 |
  | --- | --- | --- |
  | 便携 zip（含 install.ps1 与所需组件） | 内测期产物 | `target\portable\ai-zhu-ye-ime-<ver>-test.zip`，随 Releases 发布 |
  | Windows exe 安装包 | 规划中 | 打包器（如 NSIS/Wix 类）与签名纳入 M13 发布流程；就绪后随 Releases 资产提供，站点仅放直链 |

- 拿到发行包后的步骤：解压 → 管理员运行 `install.ps1` → 系统键盘设置启用 → 开始输入
- 卸载与用户数据保留说明；`verify-tsf-identity` 复核提示省略（开发者细节指向文档页）

### 5.4 隐私页（FR-055）

- 默认零网络：输入内容只在本机处理；初始配置下不发起任何网络请求
- 唯一联网组件：词典在线更新器，`online_update` 默认关闭，显式开启才联网
- 数据位置：用户词/配置/日志在 `%APPDATA%\ai-zhu-ye-ime`；程序文件在
  `C:\Program Files\ai-zhu-ye-ime`
- 卸载保留用户数据（属用户财产），可手动删除目录
- AI 能力为预留接口，默认关闭，无上传行为
- 本站自身：无第三方脚本、无统计（NFR-012）

### 5.5 关于页（FR-056）

- 项目简介：Rust 编写、TSF 架构、GDI 自绘候选窗；Windows 10/11 x64
- 站内状态口径由共享 header/footer（版本状态行）与首页承担，关于页不再单设"当前状态"节
  （用户要求精简；T-061/T-080 欠账口径仍在 header/footer 版本状态行如实呈现）
- 许可：`MIT`；第三方数据来源与许可证见 `docs/licenses.md`
- **站内不点名第三方/竞品**：由于用户要求，页面不出现「青简」「搜狗」等第三方名称与竞品
  指认；借鉴留痕按 AGENTS.md 仅存于仓库文档（本设计 §12 借鉴模式清单、docs/竞品和参考.txt）
- 链接：GitHub 仓库、Releases、文档

### 5.6 404 页（FR-051 附）

吉祥物探头姿态 + "这片竹林里没有这个页面" + 回首页链接。

### 5.7 AI 与机器可读入口（FR-058，D-69）

站点根提供四个文件，全部为静态文本/XML，零脚本、零外部依赖：

| 文件 | 格式与作用 | 关键约束 |
| --- | --- | --- |
| `llms.txt` | 遵循 llmstxt.org v2：`# 标题`（必填）+ `> 摘要` blockquote + 项目说明段 + `## 分节`文件列表 `- [名称](相对链接): 说明`；文件保持小而准，细节走链接 | 与页面同口径（NFR-011）；链接用相对路径随宿主前缀自适应 |
| `agents.txt` | 面向 AI 代理的站点导读：项目事实、内容边界（哪些是规划中）、可信路径指引（下载一律看 Releases） | 无统一国际标准（多个提案并存），**本站格式约定见 S-18**，写入 README 与验收断言 |
| `robots.txt` | `User-agent: *` + `Allow: /`，指向 `sitemap.xml` | 不屏蔽任何爬虫 |
| `sitemap.xml` | 6 个页面的 `<urlset>`，lastmod 随页面更新 | 绝对 URL 暂钉默认 Pages 地址（`https://<owner>.github.io/<repo>/`），部署自定义域后必须更新（README 已注） |

## 6. 品牌资产设计（FR-057）

### 6.1 logo（`logo.svg` / `logo-mark.svg`）

- **图形**：一片竹叶 + 一茎二叶的组合——由两条对称贝塞尔曲线构成叶片外轮廓，中心一条叶脉
  曲线；一茎二叶模拟风中的竹叶扇形，整体呈负 30° 倾斜的动势
- **配色**：叶片 `--leaf` 到 `--leaf-deep` 的轻渐变（SVG `linearGradient`），叶脉留白
- **组合**：图形 + 「竹叶」字标（700 字重）+ 小字 `ZHUYE`（字距拉开）
- **变体**：`logo-mark.svg` 仅图形，用于 favicon（16/32px 下细节依然可辨：叶片粗轮廓、无渐变）

### 6.2 吉祥物（拟人化竹叶）

- **母题**：一片直立的竹叶 + 头顶一段小竹节茎（像天线）+ 圆点眼 + 微笑 + 细长手臂 + 小脚；
  与 logo 使用同一叶片外轮廓曲线家族，保证品牌统一
- **姿态**：`mascot-hero.svg`（站姿，双手放身后，用于首页 hero）；`mascot-point.svg`
  （侧身单手指向，用于文档/下载页引导位）；`mascot-404.svg`（从页面边缘探头）
- **配色**：叶片主体 `--sprout`→`--leaf` 渐变，脸部 `--ink`，腮红 `#E8C9C0`（少量暖色点缀，
  常开不喧宾）；深色背景版本在 404/页脚不出场，避免额外维护（S-13）

### 6.3 候选窗示例插图（`cand-window.svg`）

如实复刻候选窗（S-15）：白底圆角、蓝色边框、页眉条（组合串 `nihao` + 拼音提示）、三行候选
（序号 + 蓝字中文 + 右侧灰字英文译文、选中行浅蓝块红字）、页脚 `1/2`。画面右侧吉祥物 v 字
手势，气泡文案「候选词旁，有译文。」——文案须与产品真实行为一致。

### 6.4 版权与再生成规则

- 全部 SVG 手写自绘，无第三方素材、无 AI 生成（D-65）；随仓库 `MIT OR Apache-2.0`
- 修改产品候选窗配色后必须同步更新 `cand-window.svg`（S-15 联动义务）

## 8. 实现约定（site/）

- 单份 CSS `site.css`：`:root` 令牌 + 基础排版 + 组件（header/footer/特性格/标签页/键位表/
  候选窗插图容器/路线图块/表单与按钮）；移动端断点 `max-width: 720px`
- HTML 结构：`<header class="site-header">`、`<main>`、`<footer class="site-footer">`；
  每个 `<main>` 首行标题；`<a>` 必须有可见焦点样式（`:focus-visible` 竹叶绿外环）
- 每页 `<title>`（含「竹叶输入法」）与 `<meta name="description">`；首页 JSON-LD
  `SoftwareApplication`（name/operatingSystem=Windows/applicationCategory=Utility/
  license 等）
- 可访问性：对比度（正文 `--ink` 对 `--paper` ≥ 12:1；次要文字 `--muted` ≥ 4.5:1）、
  `aria-current="page"`、`alt` 文案、`prefers-reduced-motion` 关闭全部动画
- 无 JS 文件；无外部字体/图标/SVG（内联状态图标除外）
- **AI 入口维护**（FR-058）：`llms.txt` 链接指向站点页面；`agents.txt` 为站点自有结构
  （S-18）；`robots.txt`/`sitemap.xml` 与页面集合一致；页面增删必须同步这四个文件，
  提交前由验收断言与 `check-site-links.ps1` 复核

适用范围

  • Windows 10/11 x64
  • 现代 TSF 应用：记事本、浏览器、IDE、Office 等
  • 提供全拼中文输入、候选区中英译文、译文层切换与本地用户词学习
  • 默认完全离线，不收集输入内容

安装

从 下载页 或发布渠道取得发行包 ai-zhu-ye-ime-<version>-test.zip，解压到目标机后以管理员身份 打开 PowerShell，运行包内脚本：

.\scripts\install.ps1

发行包模式不依赖源码树与 Rust 工具链：脚本从包内 bin\ 取 TSF 输入法 DLL、设置窗口、 更新器与基础词典，从 packs\ 预置三个领域包（it/med/ slang）到 %APPDATA%\ai-zhu-ye-ime\packs\，并创建开始菜单快捷方式。

重复安装安全：每次安装先清理旧注册再重建，不会产生重复路径；旧版本 DLL 由系统重启后延迟清理。 升级为同名覆盖，保持幂等。

启用与切换

安装完成后进入系统设置：

设置 -> 时间和语言 -> 语言和区域 -> 中文（简体，中国）-> 键盘

确认「竹叶输入法」已列出并启用。日常输入使用系统输入法切换键：Win+Space 或 Ctrl+Shift（取决于系统设置）。安装后无需重启系统；正在运行的应用可能 需要重启一次才会加载新 DLL。

基本使用与键位

输入全拼字母串，候选窗显示中文候选；拼音切分支持歧义路径，如 xian 同时支持 「西安」与「先」。

按键行为
Shift中英模式切换
Tab中文候选层 ↔ 译文层
Space上屏当前选中候选（默认第一候选）
↑ / ↓候选窗内上移 / 下移选中行
1 - 9上屏对应候选项
- / =（Shift+= 即 +）上翻页 / 下翻页
Enter上屏拼音原文
Esc取消本次输入

候选窗底部右端显示当前页/总页数（如 1/2），仅多页候选时显示。语言栏图标随模式 实时切换：中文模式蓝底白字「中」，英文模式灰底白字「英」。Windows 11 若任务栏不渲染第三方 语言栏图标，可在输入法「高级键盘设置」里开启桌面语言栏。

译文

中文候选行右侧以弱化样式显示英文译文。按 Tab 进入译文层，候选列表切换为英文 译文；按 1 等数字键上屏译文，上屏后自动返回中文候选层。没有译文的词不会强制 进入译文层，也不会出现空白页。

用户词

选择过的中文词会记录到本地用户词库，并在后续排序中提升权重。用户词库路径： %APPDATA%\ai-zhu-ye-ime\user_words.json。文件损坏时输入法会自动备份为 .bak 并重建空库，不影响静态词典。

升级与卸载

升级

  1. 取得新版本发行包。
  2. 以管理员身份执行 .\scripts\install.ps1（发行包模式）。
  3. 重启正在使用输入法的应用，使其加载新 DLL。

安装器会用新版本词典覆盖安装目录中的 dictionary.zyct；升级不删除用户词库与 本地配置。

卸载

以管理员身份运行 .\scripts\uninstall.ps1：删除 TSF 与 CLSID 注册表树、安装目录 中的 DLL、设置窗口与更新器、开始菜单快捷方式，并校验注册表无残留；重复执行安全。DLL 或 exe 被占用时会改为重启后延迟清理，不中止卸载。

用户词库、配置与领域包位于 %APPDATA%\ai-zhu-ye-ime，卸载默认保留 （属用户数据）；确认不再需要时手动删除该目录。

故障排查

现象处理
安装报「需要管理员权限」用管理员身份重新打开 PowerShell
安装报 DLL 被占用关闭输入法相关应用后重试
输入法不在系统列表检查「键盘」设置是否已启用；重新运行 install.ps1
切到竹叶输入法后无候选确认已通过系统切换键激活；重启应用后再试
候选窗错位/模糊确认系统缩放为受支持的 DPI；重启应用
用户词异常检查 %APPDATA%\ai-zhu-ye-ime，必要时删除或重置用户词库

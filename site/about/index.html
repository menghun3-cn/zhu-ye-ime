关于竹叶输入法

项目简介

竹叶输入法是一款面向 Windows 10/11（x64） 的轻量拼音输入法，全部代码以 Rust 编写，基于 TSF 框架接入系统，候选窗为 Win32 自绘（跟随系统深浅色、支持高 DPI 与 高对比度）。它的核心特色是：输入中文时，候选行内直接附英文译文，按 Tab 即可切到译文层上屏英文。

当前状态

  • Windows 内测版（v0.1.x）：仓库维护着 v0.1.0 发布标签，开发主线持续迭代。
  • M1–M12 里程碑的核心能力（基础输入闭环、词典体系、输入体验优化、格式候选、中英混输、 领域自动、通讯录、设置窗口等）已实现并通过自动化门禁与宿主验收； 其中格式候选与设置窗口的部分真实环境交互验收仍在收尾（验收虚拟机恢复后回填）。
  • 正式对外发布与在线更新源正在收尾；当前获取方式见下载页。

技术栈

层面选型
语言Rust（workspace 多 crate：core / dict / ime / settings / updater / cli 等）
系统接入Windows TSF（Text Services Framework）
界面候选窗与设置窗口均为 Win32 自绘（GDI），不依赖任何 GUI 框架
词典自研 v2 二进制格式 + mmap 只读加载；词典包体系带签名在线更新
对外站点本官网为零构建纯静态站（HTML/CSS/手绘 SVG，无 JS）

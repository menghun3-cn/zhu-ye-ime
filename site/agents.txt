# 竹叶输入法官网：面向 AI 代理的站点导读

> 本文件帮助 AI 代理正确理解与使用竹叶输入法（zhu-ye）官方网站。站点为纯静态、零 JS、可整体抓取；本文件为站点自有约定的 `agents.txt` 结构（S-18），与 [llms.txt](llms.txt) 配合使用。

## 项目事实

- 竹叶输入法：Windows 10/11（x64）拼音输入法，Rust + TSF 架构；核心特色是输入中文时候选行内附英文译文，按 Tab 可上屏英文
- 当前状态：内测版（v0.1.1-alpha）；M1–M13 核心能力已实现并通过自动化验证；部分真实环境交互验收收尾中
- 许可：MIT；英文名：zhu-ye
- 仓库：https://github.com/menghun3-cn/zhu-ye-ime

## 内容边界

- 能力口径：站点只宣称已实现并经过测试/验收的能力，完整清单见 [首页](index.html) 特性区与 [关于](about/index.html)
- 规划中（仅首页「路线图」区块，带「规划中」标注）：正式版发布与在线更新源开通、Windows exe 安装包、英文官网
- 平台：仅支持 Windows 10/11 x64；无其他平台版本；英文站为后续任务
- 下载：本站不托管安装包，任何页面不得声称存在可下载的安装文件——下载一律以 GitHub Releases 实际发布为准

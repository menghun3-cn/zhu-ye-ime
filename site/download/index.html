发布状态：内测阶段

竹叶输入法目前是 Windows 内测版（v0.1.x），正式对外发布与自动更新源正在 收尾。安装包（ai-zhu-ye-ime-<version>-test.zip）会最先出现在 GitHub Releases 页； 在正式版发布前，也可按仓库 README 从源码自行构建。在线自动更新源尚未开通，升级方式为重新安装新发行包。

系统要求

项目要求
操作系统Windows 10 / 11（x64）
使用场景现代 TSF 应用：记事本、浏览器、IDE、Office 等
网络不需要（默认完全离线；可选在线词典更新默认关闭）

安装

  1. 从 GitHub Releases 取得发行包 ai-zhu-ye-ime-<version>-test.zip，解压到目标机（无需安装 Rust）。
  2. 右键「以管理员身份运行」PowerShell，执行包内脚本：.\scripts\install.ps1。
  3. 进入系统设置 设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 键盘， 确认「竹叶输入法」已启用。
  4. 用 Win+Space 或 Ctrl+Shift 切换输入法，开始输入。

建议先在虚拟机或系统还原点保护下测试安装/卸载闭环。包内 scripts\verify-tsf-identity.ps1 可在目标机复核 TSF 标识（6 项）。

卸载

以管理员身份运行包内 .\scripts\uninstall.ps1，即可完整移除注册表项、DLL、设置窗口、 更新器与开始菜单快捷方式。用户词库与配置位于 %APPDATA%\ai-zhu-ye-ime，卸载默认保留；确认不再需要时手动删除该目录。

从源码构建（开发者）

需要 Windows 10/11 x64、Rust 1.98.1+（x86_64-pc-windows-msvc 目标）与 Git。 构建与发行包打包步骤见仓库 docs/安装与使用.md 与 scripts/package-portable.ps1。

竹叶输入法
输入中文，候选词旁有译文。

竹叶输入法当前为 正式版（v0.1.2，2026-10-05 发布）。发行包通过 GitHub Releases 提供并附本站直链；在线自动更新源已开通（镜像分发仓库 zhu-ye-updates， 在客户端设置中启用在线更新后自动获取；默认保持关闭、无任何网络请求）。Windows exe 安装包为 Releases 第 7 项资产，直链见下表。

发行包

形态直链说明
Windows exe 安装包（ai-zhu-ye-ime-setup-0.1.2.exe，推荐） 下载 exe 安装包 Inno Setup 图形化安装包，安装/卸载复用发行包脚本语义（版本化 DLL、TSF 注册、预置领域包、 快捷方式；卸载保留 %APPDATA% 用户数据）
便携 zip（zhu-ye-ime-0.1.2.zip） 下载便携 zip 含安装脚本、设置窗口、更新器与基础/领域词典；免安装 Rust，解压后以管理员运行 install.ps1 即可安装

校验值（SHA-256）见 Releases 资产的 SHA256SUMS.txt。全部资产以 GitHub Releases 实际发布为准；本站不托管安装包。

系统要求

项目要求
操作系统Windows 10 / 11（x64）
使用场景现代 TSF 应用：记事本、浏览器、IDE、Office 等
网络不需要（默认完全离线；可选在线词典更新默认关闭）

安装

  1. 从下表直链或 GitHub Releases 取得当前发行包（正式版 v0.1.2；exe 安装包或便携 zip 二选一），exe 直接运行安装，zip 解压到目标机 （无需安装 Rust）。
  2. 右键「以管理员身份运行」PowerShell，执行包内脚本：.\scripts\install.ps1。
  3. 进入系统设置 设置 → 时间和语言 → 语言和区域 → 中文（简体，中国）→ 键盘， 确认「竹叶输入法」已启用。
  4. 用 Win+Space 或 Ctrl+Shift 切换输入法，开始输入。

建议先在虚拟机或系统还原点保护下测试安装/卸载闭环。包内 scripts\verify-tsf-identity.ps1 可在目标机复核 TSF 标识（6 项）。

卸载

以管理员身份运行包内 .\scripts\uninstall.ps1，即可完整移除注册表项、DLL、设置窗口、 更新器与开始菜单快捷方式。用户词库与配置位于 %APPDATA%\zhu-ye-ime，卸载默认保留；确认不再需要时手动删除该目录。

从源码构建（开发者）

需要 Windows 10/11 x64、Rust 1.98.1+（x86_64-pc-windows-msvc 目标）与 Git。 构建与发行包打包步骤见仓库 docs/安装与使用.md 与 scripts/package-portable.ps1。

# Agent Note: 候选窗蓝框蓝字红选中配色

Status: implemented

[English](2026-09-25-candidate-window-blue-red-palette.md) | 中文

## 问题

T-028/T-030 后默认浅色板是搜狗经典风：白底、浅灰圆角边框、近黑色候选词、
浅蓝选中块 + 深蓝选中文字。用户指令：候选框应**蓝色边框**、**候选词蓝色**、
**选中行为红色**。

## 决策

- **浅色（默认）：** 白底 `#FFFFFF`；圆角边框 `#1E88E5`（亮蓝，与候选词同
  色）；候选词文字 `#1E88E5`；选中块保持 `#E6F2FE`（浅蓝），**选中文字红色
  `#D32F2F`**（按用户确认：红字 + 浅蓝块，不做红底）；序号与译文保持次要
  浅灰 `#999999`。
- **深色（仅显式，同构）：** 深底 `#202020`；边框 `#42A5F5`；候选词
  `#64B5F6`；选中块不变 `#3A4A5C`，选中文字亮红 `#FF8A80`；序号/译文
  `#9E9E9E`。
- T-030 的浅色默认与"深色仅显式"策略不变，只改色值本身。
- FR-009 皮肤色板验收行已按新色值更新并标注 T-032。

## 曾考虑的替代方案

**红色选中块（红底白字或红字）。**
按用户选择否决：红字配既有浅蓝块保留 T-028 块状结构且对比最佳。

**深蓝边框 + 亮蓝文字分层次。**
按用户选择否决："亮蓝"同时用于边框与候选词文字。

## 后果

VM v0.1.3 演练截图与像素直方图（shots9）为验证产物：边框像素 `1E88E5`、
首行（选中）文字 `D32F2F`、其余行文字 `1E88E5`。配色单测锁定新值。
本笔记取代 2026-09-25-candidate-window-light-default-and-empty-panel.md
中的色值表述；后者对"浅色默认"与"空候选仍显示"两项决策仍然有效。

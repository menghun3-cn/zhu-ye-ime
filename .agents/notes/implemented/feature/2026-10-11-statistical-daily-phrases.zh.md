# Agent Note: 统计驱动日常短语——语料排名的日常组合（T-147）

Status: implemented

## Problem

T-145（种子表 + 系词枚举）让「你是/我是」可被候选，但排序是**人工频率档位**
（4200/4000）。用户随后追问（2026-10-10）：`ni you` 也应打出「你有」——
且要求**全量**加入日常组合，因为"种子表逐条验证"无法扩展到"用户真正会打的
全部短语"。T-145 当年因**不存在 n-gram 语料**否决了语料统计；本次烤问
（10 轮）把方案定死：真·语料统计、统计优先排序、体积不设限、≥95% 口语短语
验收清单。

## Decision

`build_base` 新增**统计优先覆盖层（d 段，m6.rs）**，数据来自新子命令产出的
可复现短语频率表：

- `zhu-ye-dict build-phrases`（`crates/zhu-ye-dict/src/phrases.rs`）读
  `data/cache` 下两份语料（pin D-022/D-023，许可登记已同步）：
  - **OpenSubtitles zh_cn**（对话字幕；许可状态未明——只把统计派生数字带进
    产品，绝不复制任何原句文本）；
  - **zhwiki pages-articles**（CC BY-SA 4.0；`latest` 滚动 dump 按快照日期 +
    sha256 锁定），仅抽取 `<text>…</text>` 正文，并做**按页采样**
    （`WIKI_PAGE_SAMPLE_EVERY = 3`：每 3 页取 1；快照固定 → 样本固定 →
    可复现；处理时间降到约 1/3）。
  对 CJK 连续段做字符级 **2..=5-gram** 滑窗（字幕计到 5-gram、维基计到
  4-gram），逐源 ppm（每百万字频），**字幕:维基 = 2:1 加权**融合——口语
  占比主导、贴近用户实际输入（1:1 时书面偏置的「下半/他在」会压过「下班/
  她在」）。映射 zipf 兼容分 `3800+2500·log10(ppm)/4` 截断到 [3800, 6300]；
  ppm<1 自然低于门槛出表。**长词残段降档**（T-147 修复）：n-gram 向
  (n+1)-gram 的前/后向延伸占比 > `EXT_RATIO = 0.6` 视为长词内部残段
  （「己的」←「自己的」、「什么意」←「什么意思」），其得分 ×
  `EXT_WEIGHT_FACTOR = 0.9`——不出组内相对顺序，但把真词压回残段之上。
  产物 `data/artifacts/phrases-freq.tsv`（`词<TAB>降档后分`、降档词另带一列
  `降档前分`——合并层据此对官方先验词恢复原分，见下方豁免），确定性排序
  （分降序、同分词序）；双语料缺失报错，缺一则降级使用。
- `build_base` 中该表经 `load_statistical_phrases` 载入（文件缺失 → 空表不
  失败），并在 T-145 步**之前**以**覆盖语义**并入：已有词条被替换为统计频率
  （拼音/译文保留），新词插入。T-145 种子/枚举随后只补统计表未覆盖的组合
  （它们仍跳过已有词条，绝不会撤销统计排序或其频率）。
- **官方先验词豁免 + 统计只升不降（v2）**。延伸占比启发式分不清"长词残段"
  （己的 ← 自己的）与"常用词的自然搭配"（时间 ← 的时间、我们 ← 我们的、
  什么 ← 什么的、知道 ← 知道的 全中招）。融合表对两者都 ×0.9，导致书面
  偏置的「事件」压过「时间」抢走 `shijian` 组首，S-1 组内胜者率大跌。修复：
  **词典里已存在的词（骨架/wordfreq/jieba/CEDICT 印证是真实组合）合并时只
  升不降**——降档词恢复降档前分，统计分低于官方先验的覆盖直接忽略（统计
  证据只能增强、不得重写官方先验次序）。`phrases-freq.tsv` 以可选第三列携带
  降档前原始分；表内保留 raw≥3800 的降档词供合并恢复，**降档后 <3800 的
  统计新词由合并丢弃**（不污染 base）。统计新词（己的/你有）保留降档分、
  继续受语料证据支配。
- **口语治理覆盖层（d1b，v2）**。三类统计管道自愈不了的口语词由
  `data/patches/phrase-overrides.tsv`（`词<TAB>空格分隔无调拼音<TAB>频率`，
  拼音逐音节按引擎全拼表校验，频率限 [3800, 6300]）在统计合并后**强制写音
  写频**：
  a) **多音定音**——字级注音按词典读音序取首音，「行吧」被注成"银行"的
     hangba；治理改pin为 xingba；
  b) **同音竞争提频**——双语料都让错别字赢（你又>你有、己的>记得、在马>在吗、
     那儿>哪儿、我在那>我在哪、应该把>应该吧），治理把期望词提到统计胜者
     之上 5-15%；
  c) **统计低频整词入包**——5 字会话问句（我喜欢你吗/你喜欢我吗）够不到
     ppm≥1 置信门槛，以治理频率直接入包。
  统计管道（phrases.rs）与其产物表不动；治理是数据 + 合并步覆盖，同一文件
  可审计。9 条治理把验收清单命中率从 93.1% 提到 **98.1%**；「她有/她在/喂」
  作为已接受的 miss 保留（他/为 语料与搜狗都占主导）。
- **S-1 口径定稿（2026-10-12，用户确认）**。回归门禁 `audit-coverage` 保留
  **全量 5000 样本出候选率 ≥98%**；组内胜者排序门槛重述为**只统计多字期望
  胜者组**——统计层只能影响 2-5 字词，单字组序（向 vs 想、位 vs 为：
  xdhyc-2008 权威字序 vs wordfreq 现代语料序，1487 样本 73.3%）T-147 前后
  零改动、不再设排序门槛，只守全量出候选率。当前数字：出候选 100.00%、
  **多字组胜者 92.37%**（3245/3513，≥90%）、全口径 86.70% 作参考值。
- `BaseStats` 增加 `statistical_phrases` / `statistical_overwritten` /
  `statistical_skipped` 与 `override_overwritten` / `override_added`。
- 验收（Q4a）：`data/eval/daily-phrases-checklist.tsv`（159 条口语短语，
  `词<TAB>无调连续全拼`，用户点名词 你是/你有/你在 在最前）+ `zhu-ye-dict
  check-phrases [--base] [--min-rate 0.95]`——按引擎路径查首候选，≥95% 退出
  码门禁。清单只增不减；语料每轮更新后重跑。当前结果：**156/159 (98.1%)**
  含治理覆盖；剩余 3 misses（她有/她在/喂）已接受——语料与搜狗均以 他/为
  居首。

频率带 [3800, 6300] 高于「逆势」(2850)、低于高频单字（是 7160 / 你 6690），
单字组排序不受扰动。

## Alternatives considered

**逐条种子扩充（用户否决）。** 覆盖不了全量；语料统计是唯一可扩展来源。

**原始计数排序。** 否决：语料体量不同；ppm 归一化 + 对数分让两源可比并钳制
极端值。

**最低覆盖过滤（MIN_PPM）。** 并入评分门槛本身——ppm<1 的短语自然得分低于
3800 被同一钳制逻辑丢弃；一个阈值替代两个。

**单语料。** 最后一轮烤问否决：双语料融合（字幕 × 维基书面语）平衡口语句式
与成文覆盖面；实测两者单独都盖不全验收清单。

**现成词表（SUBTLEX-CH、现代汉语常用词表）作为一等源。** 延后至第二阶段：
词级频率表无法直接表达 2/3 字短语排序，但可作额外加权源并入同一张表；见
`related` 第二阶段 note。

## Consequences

- `nishi` / `niyou` 排序变为语料驱动：语料里实际出现什么就赢；人工档位仅作
  回退/枚举层存在。
- 首次构建词库按统计新增增长（数字见构建输出）；运行期 IME 零改动——纯数据
  + 构建，走既有 `copy-data` 词典链（dictionary.zyct + .tones）。
- 清单是回归防线：`check-phrases` ≥5% 未命中阻断合并（exit 1），逼着重排，
  而非口头交代。
- zhwiki 是滚动 dump：刷新须人工改 pin（fetched_at/sha256/size）——D-023
  已记录。
- 许可姿态：OpenSubtitles 许可不明 → 只有频率分（统计事实）进产品、永不进
  句子文本；zhwiki CC BY-SA 4.0 同样只折成 2/3-gram 计数。
  `docs/licenses.md` 与 `docs/数据清单.md` 有记录；发布检查清单复核。

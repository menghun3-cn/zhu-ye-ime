# Agent Note: 网络语包与构建期内容把关（M6-P）

Status: implemented

[English](2026-09-28-slang-pack-and-content-gate.md) | 中文

## Problem

M6 要发布网络语包（FR-016/017），其中有两类词条：一类是按普通拼音输入的纯中文网络词（内卷、破防），另一类是字母/数字缩写（yyds → 永远的神）。市面上没有许可干净、可 pin 锁定的网络语语料，公开候选池都是未审核的众包文本。FR-021 还要求内容把关：脏话、政治敏感、广告类词条漏放为 0，误杀 ≤5%，每次构建都要记录把关表版本与命中数据；负面清单本身不得进入发行物。缩写同样有风险：`wo`、`emo` 这类键也能切分成拼音音节，放进缩写路径会污染正常输入。

## Decision

`zhu-ye-dict build-slang`（`crates/zhu-ye-dict/src/slang.rs`）读取 `data/slang/` 下三份提交入库的项目自有输入，构建 `data/artifacts/slang.zyct`：

- `seed.tsv`：`词<TAB>键<TAB>类型<TAB>来源`。类型 `词` 为纯中文网络词：键空时按 CC-CEDICT 词级 → kTGHZ 字级注音；键非空时是撇号分隔的全拼（用于多音字词，如 `长草 zhang'cao`），逐音节校验。类型 `缩写` 的键直接写入 v2 词条的拼音字段。每行都必须带来源注释。
- `blocklist.tsv`：`词 模式 类别`，必须有 `# version:` 行。模式分四种：`包含`（子串）、`精确`（整词）、`放行`（豁免串，完整覆盖某处子串命中时豁免该处，如「大麻烦」覆盖「大麻」）、`缩写键`（缩写键精确匹配）。比较前先归一：全角 ASCII 转半角、字母转小写、去掉空白。
- `gate-samples.tsv`：`标签<TAB>类型<TAB>文本`，存放正负抽查样例。

构建先抽查、后过滤。抽查把全部样例过一遍把关表；负例或正例不足 200、任一负例漏放、误杀率超过 5%，三者任一发生即构建失败。抽查通过后才过滤种子表：被把关命中的行记入报告并丢弃。缩写键要求是至少 2 位的小写字母/数字；纯字母键不得整串切分为标准全拼（`segment_all` 结果为空）。不合格的键记入排除清单，绝不"修正"后转入拼音路径。所有词条统一词频 5000（与 base 同为 zipf×1000 尺度的中频值）。报告写入 `data/artifacts/slang.gate.json`，内容包括把关表版本、抽查统计、误杀条目及命中串、把关拦截行、排除行、大小与 SHA-256。该文件是与包同目录的构建产物，不进 manifest。

2026-09-28 实测：负面清单 151 条（版本 2026.09.28-1）。负例 310 条（原形加上下文、大写、全角、空格变体），全部拦截。正例 453 条（种子表全部词条加易误杀的良性词），误杀 1 条（0.2%，`屌丝` 命中 `屌`，作为可审计的已知误杀保留）。种子 413 行 → 纯中文词 319 + 缩写 92；`wa`、`emo` 因可切分被排除；最终 411 词条，26,248 字节，两次构建字节级一致，已纳入 manifest 2026.09.28-p3。

## Alternatives considered

**现在就引入 `social-media-chinese-words` 等众包词池。** 暂缓：这类词池的质量与许可需要逐条审核。种子表加把关已经提供了一份经过审核的基线，词池以后可以作为候选来源，经同一道把关并入 `seed.tsv`。

**只过滤、不做样例抽查。** 否决：负面清单能让种子表"通过"，并不能证明它既不漏放也不误杀。有了抽查，FR-021 的门槛才成为可执行的构建门禁。

**可切分的缩写（`emo`、`wa`）照样按缩写入包。** 否决：方案 11.4 禁止可切分串进入缩写路径，否则输入 `emo`/`wa` 时网络语会混进普通候选流。

**随包发布负面清单，供运行时过滤用户输入。** 否决：把关是构建期的质量控制手段，随包发布等于在安装包里附带一份不当用语目录。

## Consequences

- 收益：每次构建网络语包都会用自身输入证明满足 FR-021；报告提供带版本的审计记录；缩写规则在构建期强制执行，运行时缩写路径（M6-R）可以信任包内每个字母键。
- 成本：种子表与负面清单需要每次发版人工维护；抽查样例要随负面清单一起增长，"各 ≥200"才有意义。数字键（996、520）已入包，引擎自 T-049 起可输入到这些词（见[数字缩写键笔记](../bug-fix/2026-09-29-digit-abbreviation-key.zh.md)）。
- 运行时查询、候选组尾部排列与 `[网络]` 标注属于 M6-R，本笔记只覆盖构建侧。
- 不取代任何既有笔记。本笔记扩展 [领域词包构建与 manifest 管线](2026-09-28-dictionary-pack-build-and-manifest.zh.md)；任务在 [todos-list](../../../../docs/todos-list.md) 中登记为 T-045。

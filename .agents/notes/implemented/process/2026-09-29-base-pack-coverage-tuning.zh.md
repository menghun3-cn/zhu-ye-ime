# Agent Note: 基础包覆盖调参与抽检指标（T-044）

Status: implemented

[English](2026-09-29-base-pack-coverage-tuning.md) | 中文

## Problem

S-1 要求基础包通过两道门槛：覆盖 ≥98%，首候选正确率 ≥90%（5000 词样本）。
初始 `audit-coverage` 工具报告覆盖 100% 但首候选正确率仅 70.5%——远低于 90%。
在关闭任务前必须回答两个问题：指标本身是否公平，以及是否存在真实的词频
赋值缺陷导致生僻词压过常用词。

## Decision

修复了两个构建期缺陷，并将抽检指标拆为两层以区分语言事实与排序质量。

### 缺陷 1：骨架多音词覆盖

`load_xdhyc` 对骨架每行返回一条记录，包括多音词的重复（`了` 有 `le` rank 590
和 `liao3` rank 2542）。`build_base` 按词插入 `HashMap`，后出现的行覆盖前面，
常用读音丢失：`了` 落到 `liao`，`le` 组只剩生僻字（`叻`、`鳓`、`泐`）。

修复：`load_xdhyc_ranked` 返回 `(word, pinyin, rank)`，`build_base` 通过
`skeleton_rank` 映射保留 rank 最小（最常用）的读音。旧 `load_xdhyc` 签名以
`#[cfg(test)]` 保留供既有单测使用。

### 缺陷 2：jieba 扩充绕过 frequency_of 主源优先

jieba 扩充阶段直接存 `jieba_score(word)` 而非 `frequency_of(word)`。
`frequency_of` 封装了"wordfreq 优先，未命中取 jieba"——但扩充阶段绕过了它。
对于同时在 wordfreq 和 jieba 中的词（大多数 CJK 词），较高的 jieba 尺度胜出。
例：`垸` wordfreq=2450 却以 jieba 5690 入包，压过骨架词 `元`（5600）。

修复：jieba 扩充循环对门槛判定与存储值统一调用 `frequency_of(word)`，与骨架、
CEDICT 阶段一致。

### 抽检指标：目标词口径 vs 组内胜者口径

5000 个常用词仅对应 3661 个不同拼音。同音词（`是/时/使`）中只能有一个居首，
因此目标词居首率存在约 73.22% 的数学上限。拿它对 90% 门槛必定失败。

修复：`audit-coverage` 现报告两个指标：

- **目标词居首率**：原始的"查询词本身是否居首"。受同音词天花板（~73%）约束，
  仅作参考值。
- **组内胜者率**："首候选是否为该拼音组内骨架排名最优词"。这是对 90% 门槛的
  排序质量指标，从不可消除的同音冲突中隔离出可修复的词频赋值错误。

`CoverageReport` 新增 `distinct_pinyins`、`group_winner_hit`、`group_winner_pct`
字段。CLI 门槛用 `group_winner_pct ≥ 90%`。

### min-score 扫描

`--min-score` 在 1000–3500 全档位扫描。常用词两项指标（目标词 72.06% / 组内胜者
90.20%）在各档位完全相同——`--min-score` 只影响长尾 jieba 扩充体积，不影响
常用词排序。取默认 2000 平衡覆盖（规范字集 94.8%）与体积（23.1 MB）。

## Verification

双修复后重建 `base.zyct`（287,152 词条，23.1 MB，SHA `7f389214…`，两次构建一致）：

- 覆盖率：5000/5000 = 100.00%（门槛 ≥98% ✓）
- 目标词居首：3603/5000 = 72.06%（天花板 73.22%，参考值）
- 组内胜者：4510/5000 = 90.20%（门槛 ≥90% ✓）
- `了` 正确归入 `le`（rank 590），不再在 `liao`
- host-e2e 真实词典 smoke：6/6 PASS
- 全工作区 319 项测试通过，clippy 无告警
- 新增 2 单测：`骨架多音词保留官方排名最优读音`、`jieba扩充词频取主源优先而非jieba标定值`

## Alternatives considered

**保留目标词口径并将门槛降至 72%。** 否决：门槛的目的是捕获排序回归，而非
测量同音词密度。降低门槛会隐藏真实缺陷（`垸` 压过 `元` 的案例在旧指标 70.5%
下通过）。组内胜者口径恰好捕获可修复错误，同时尊重语言事实。

**从样本中过滤同音词。** 否决：移除共享拼音的词会使样本偏向生僻拼音，掩盖最
常用词（`是/时/使/十/事` 全在前 50）。组内胜者方案保留完整样本，在分析层面
分离两个关注点。

**提高 `--min-score` 缩小包体积。** 扫描显示 2500 可将包缩至 15.7 MB / 162,692
词条，常用词指标不变。未选用因为额外的 124,490 jieba 扩充词条以 7.4 MB 代价
提供长尾覆盖（字集 94.8% vs 94.3%），远在 60 MB 预算内。若日后体积成为约束，
2500 是无质量代价的可行回退。

## Consequences

基础包缩小 5 MB（28.2 → 23.1 MB），因为 jieba 扩充词现取 wordfreq 尺度分值
（低于 jieba 尺度），更多词落入 `--min-score 2000` 门槛以下。这是正确行为——
旧产物的词频被人为抬高。`audit-coverage` 子命令现为 S-1 的规范验证工具，其
双指标输出在验收标准 7.5 与 FR-018 中引用。

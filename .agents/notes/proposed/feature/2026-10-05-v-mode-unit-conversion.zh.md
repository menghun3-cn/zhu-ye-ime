# Agent Note：v 模式单位换算全量表（T-104，D-02/13.3 修订）

Status: proposed

English | [中文](2026-10-05-v-mode-unit-conversion.zh.md)

## Problem（问题）

需求 13.3 原定「不引入单位换算全量表；v 模式初版只有一页常用符号」。用户点名
清单批三明确要求「v 模式单位换算全量表」——修订该非目标：`v` + 单位键给出该
单位与同族常用单位的换算候选。

## Proposal（方案）

1. **核心表**（`zhu-ye-core/units.rs` 新增——零 Windows API）：
   - `UNIT_CONVERSIONS`：23 键 × 每键 ≤9 条等值换算串，覆盖 9 类——长度
     （mi/chi/li）、面积（mu/gongqing）、体积（sheng/fang）、质量
     （kg/jin/liang/dun）、时间（miao/shi/tian）、温度（she/far）、速度
     （kmh）、数据量（kb/mb/gb）、角度（du/rad）。
   - `unit_key_prefix(key)` 与 `unit_candidates(key)` 提供按键查询。
   - 数据口径：SI 倍数精确；市制按通认折算（1 米=3 市尺、1 市斤=0.5 千克、
     1 市里=0.5 千米）；英制/温度按常用近似值固化（4-7 位小数）；温度含定点
     等价行（0 摄氏度=32 华氏度=273.15 开尔文）与温差行。全部静态、可审查、
     确定性——非外部数据源。
2. **ime v 模式单位态**（`zhu-ye-ime/input.rs`）：
   - `v_code`/`v_accepts` 接受单位键前缀字母（`vm` 等待 `vmi`/`vmiao`）；
     完整键出候选、前缀未完无候选。
   - 符号类型码（`1-9`/`x`/`h`）只在「等待类型码」（纯 `v`）时接受；单位码
     进行中字母一律按单位判定（`vs`+`h` 构成 `sh`，不触发标点组）。
   - `v_consume` 回退拼音时并入已收单位字母（`vm`+`x` → `vmx`）；已定符号码
     （`v1`+`i`）仍按原语义回退 `vi`。
   - 候选来源沿用 `Symbol`（v 模式候选统一语义，UI 不新增标签）。
3. **TSF 键路**（`zhu-ye-ime/tsf.rs`）：v 活跃时字母键统一走
   `engine.v_accepts(c)`，替换原先硬编码的 `x|h` 判定。
4. **边界**（刻意、文档化）：
   - 单位键不以 `x`/`h` 开头（符号首键码保持优先）；
   - 已定符号码（`v1`）后单位字母被拒（符号选择语义不变）；
   - 原有回退保持：`vi`/`vx` 型退出、纯 `v` 不出候选。

## Alternatives considered（备选方案）

- **运行时按系数换算**：查询时计算字符串。放弃——静态串可审查、逐族精确
  （温度定点、奇偶英制比例），确定性天然成立。
- **新增 `CandidateSource::VUnit`**：放弃——v 模式候选本就一个 UI 语义
  （无标签），`Symbol` 同时覆盖两类；新变体会波及所有匹配点而无用户可见增益。
- **只用长键（如 `vpingfangmi`）**：8+ 字母键不友好；短键 + 前缀续输
  （`vm`→`vmi`/`vmiao`）让整表"全"而输入仍快。

## Acceptance criteria（验收标准）

- workspace 全绿：core units 5 测试；ime lib 197（新增 6 项开关测试）；
  fmt/clippy(-D warnings)/diff-check 干净。
- host-e2e：`--m9` 真实词典 19/19（新增 vmi 换算/vjin/选中上屏/v1 边界）；
  seed 回归 + m7 27/27 + m10 12/12 + m12 9/9。
- 文档：需求 §13（目标 2、非目标行修订注、D-02 行、FR-028+验收方向）、
  格式候选设计 §4.1.1 整表 + §4.2 恢复、验收 §9 FR-028 +6 行。

## Risks（风险）

- **`vi` 回退范围变化**：单位键前缀字母（如 `vm`）现在留在 v 模式。实际
  拼音没有 `v`+这些辅音开头的合法组合，且 v 模式有完整 Esc/退格控制；
  非前缀字母回退（`vi`）不变。
- **vmi/vmiao 歧义**：`mi` 是 `miao` 的前缀；输 `vmi` 出米（此时完整键命中），
  续输出秒。已在单位表与前缀续输测试中文档化。
- **静态近似漂移**：英制/温度常量是常用近似值；将来需要更高精度是 units.rs
  的纯数据修改。

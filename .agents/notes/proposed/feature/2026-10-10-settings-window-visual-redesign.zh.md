# Agent Note：设置窗口视觉改版（FR-064，T-148）

Status: proposed

English | [中文](2026-10-10-settings-window-visual-redesign.zh.md)

## Problem（问题）

设置窗口（`zhu-ye-settings.exe`）自 T-073 起为 Windows 原生中性风（白底、淡蓝选中
`#E1EEFB`/`#1E88E5`），T-125 只规范了排版。窗口与官网已确立的
[竹叶品牌](../../implemented/architecture/2026-10-03-official-website-and-brand-assets.md)
毫无关联，读起来是"任何设置框"。2026-10-09 两轮 grill-me 后用户锁定**只做视觉改版**：
"只换面容，不动骨骼"。[设置窗口设计](../../proposed/architecture/2026-10-01-settings-window-process-and-registration-ownership.md)
的骨架、已验收度量与交互机制全部不动。

## Proposal（方案）

1. **范围——只换面容**：改颜色、字重层级、控件形态；窗口 880×700、导航 200、
   行高 76、标题区 80、字号体系 16/13/24（T-125 验收值）、三页信息架构、
   chips 二选一/占位展开/子视图/浮层面板交互、候选窗蓝色系验收值全部不动。
2. **品牌姿态——只出现一次**：令牌来自官网竹叶家族，按控件用途上调 UI 亮度档
   （同色相、交互安全亮度）。唯一图形是**导航列顶部的品牌块**（logo 曲线家族
   22px 竹叶图形 + 「竹叶输入法」16px/600 + 1px 竹节棕细线）。无吉祥物、无花纹、
   无渐变。
3. **两套主题，跟随系统**（D-30 不变；高对比仍完全走系统色）：浅=竹纸
   `#F7F9F4`/墨 `#22302A`/叶 `#3D7A4E`；深=墨绿黑底 `#1F2822`/亮叶 `#80B98A`。
4. **一种选中语言**：导航与 chips 选中 = 淡叶底 + 深叶字（机制不变只换色）；
   实底叶色只用于按钮与面板选中格。深色实底按钮用**墨字** `#10241A` 配 `#80B98A`
   （7.15:1）——白字仅 2.3:1 不达标。
5. **GDI 边界**：全部面容今日即可表达（实色、1px 细线、圆角矩形、ClearType 文字）；
   无渐变/投影/半透明/动画；未来 D2D 仅作为文档里的非目标留记。
6. **配置兼容**：新增主题键（`on_accent`、`chip_border`、`tag_bg`/`tag_text`/
   `sprout_dot`、`ok_text`）全部可选——自定义 `themes\*.json` 缺键回退内建默认；
   不升 `CONFIG_FORMAT_VERSION`（沿 T-088 宽松解析文化）。高对比映射照旧全量覆盖。
7. **交付**：单文件 HTML 视觉稿（`design/settings-window/mockup.html`，`file://`
   直开，最小内联 JS 仅作演示）+ [docs/设置窗口视觉设计.md](../../../docs/设置窗口视觉设计.md)
   （实测 WCAG 对比度表 + GDI 实现映射：每个令牌 → `theme.rs` 现有/新增字段，§9）。
   GDI 实现为独立任务（T-149），待视觉稿用户目检通过后启动。

## Alternatives considered（备选方案）

- **全量竹叶品牌化**（吉祥物、叶纹、每页品牌条）：放弃——设置窗口是日常高频
  工具界面；"颜色 + 一个品牌块"的克制匹配它，官网保留丰富表达的场所。
- **保持现状中性风只做打磨**：放弃——用户简报与两轮拷问都要求有辨识度的身份，
  该选项保留"任何设置框"的缺陷。
- **内容区顶部通栏品牌条**：放弃——吞掉 48px 内容度量、削弱 T-125 首屏断言；
  导航列位置承载同样的品牌重量且**零度量影响**。
- **渐变/投影/半透明**：放弃——GDI 无法表达；为装饰效果引入 D2D 与窗口
  零框架架构相悖。
- **深色按钮白字**：放弃——实测 2.3:1 低于 WCAG；墨字 `#10241A` 配 `#80B98A`
  达 7.15:1。
- **候选窗一并改绿**：出范围——其蓝色系被验收锁定（T-030/T-032/T-037/T-043）
  且带 S-15 官网插图联动义务；蓝绿并存在官网已有先例。

## Acceptance criteria（验收标准）

- 视觉稿用户目检通过：`file://` 直开、无外部请求；浅/深各覆盖三页、占位展开、
  修复与诊断子视图、emoji 与符号面板。
- 全部最终令牌色对实测 ≥4.5:1（设计文档 §4 表；正文与深色主体多达 AAA）。
- 实现映射表逐行落地：上线窗口不存在未映射的视觉元素。
- 实现批次（T-149）：`--shot` 深浅两态 BMP——像素采样等于令牌值、两态互异；
  自定义主题缺新键回退不崩溃（单测）；高对比走系统色；首屏行数断言不变
  （品牌块在导航列内）。
- 门禁全绿：fmt / clippy `-D warnings` / workspace test / diff-check /
  verify-agent-notes / verify-translation-pairs。

## Risks（风险）

- **"侧栏 + 绿色强调"滑向模板**：靠三个项目专属信号缓解——纸面层级（导航面比
  纸面深一档）、竹节棕只出现在品牌块下、新芽只作为"规划中"记号；评审若仍偏弱，
  回退手段是加强竹节棕的分隔角色。
- **实现者把深色墨字"修正"回白字**：设计文档记录了 2.3:1 否决的实测依据，映射表
  显式写明墨色值。
- **自定义主题文件与新键**：可选键回退有单测覆盖，行为延续 T-088 宽松解析文化。
- **彩色 emoji 与 GDI 单色面板落差**：视觉稿用彩色系统字形仅演示布局；T-074
  已知限制（单色轮廓 + 拼音别名）在视觉稿页脚重申。
- **与官网令牌漂移**：竹叶家族共享；官网换色必须同步本设计（与 S-15 同精神，
  记于设计文档 §12）。

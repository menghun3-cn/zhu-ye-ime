# Agent Note：口语联想覆盖表（T-105，T-058 数据项）

Status: proposed

English | [中文](2026-10-05-spoken-suggestion-overrides.zh.md)

## Problem（问题）

T-058 联想整词来自 bigram 语料（OPUS GlobalVoices 新闻语体），"怎么样/不错"
等口语后继不在高频区（"今天→的/是/早上/我/在"）。用户点名清单要求替换 T-058
**数据项**为口语语料。换语料源重建 bigram 需动许可证、管线与 23MB 产物，只为
一个行为目标；确定性、可审查的数据层更贴合项目静态表传统（emoji/units/多音补丁）。

## Proposal（方案）

1. **core 静态口语覆盖表**（`zhu-ye-core/spoken.rs`）：
   - `SPOKEN_SUGGESTIONS`：31 个高频日常前词 → 口语后继整词（每词 ≤5 条，
     "天气→不错/怎么样/很好/挺好/很冷"，"今天→天气/怎么样/下雨/忙/累"，
     "你→好/在吗/知道/觉得/想"，…）。
   - `spoken_overrides(previous) -> Option<&'static [&'static str]>`：前词
     整词匹配，不做分词。
2. **合并规则**（suggestion.rs `suggestion_candidates`）：
   - 命中：整词区完全采用口语列表（截断至 `SUGGESTION_WORD_CAP`）；短语区仍由
     bigram 短语合并（"今天早上/今天天气"保持有用）；总量 ≤ `SUGGESTION_CAP`
     不变。
   - 未命中：整词区维持 bigram 统计原逻辑（未覆盖前词语体、排序行为零漂移）。
3. **保证**：
   - T-057（Top1/Top3）断言不受影响：联想仍只出现在上屏后空闲窗，不参与拼音
     候选排序；
   - 确定性、离线、无新许可义务（人工维护的中性日常口语词，无第三方内容——
     与简拼/模糊音音节表同口径）；表规模与格式由测试强制。

## Alternatives considered（备选方案）

- **导入口语语料重建 bigram 产物**：放弃——新许可证登记、管线改动、23MB 产物
  重建只为单一行为目标；批量数据不可逐条审查。
- **口语表与语料分数混排**：放弃——非线性排序微妙改变未覆盖词行为；整词区
  完全替换是干净、可审查的契约。
- **仅前词整词表**：采纳（短语型结果已由 bigram 短语区给出；联想触发点就是
  单个已上屏词）。

## Acceptance criteria（验收标准）

- core：spoken.rs 3 测试（命中/未命中/全表格式与规模预算 30..=512）；suggestion
  +3（整词区替换、短语区合并、未覆盖保持统计）；workspace 全绿。
- host-e2e `--m8` 真实词典 8/8："今天"联想首条=口语覆盖「天气」；上屏「天气」后
  继续联想非空（口语表 + bigram 短语）；未覆盖前词保持统计路径；生命周期
  （字母退出、Esc 清空）不变。
- e2e.ps1 全量回归绿；文档已更新（需求 §13 注、设计 §3.1 + 样例表注 + §5 验收）；
  todos T-105；双语 Agent Note。

## Risks（风险）

- **"今天"契约迁移**：m8 原断言首条"的"（语料），现口语表拥有"今天"→断言迁移为
  "天气"。这正是数据替换意图；生命周期断言不变。
- **表陈旧**：31 个前词是精选种子；扩充是纯数据编辑，格式测试守住预算。
- **过度替换风险**：被覆盖前词完全失去语料信号。刻意采纳——覆盖集小且口语措辞
  贴合场景 5 用户期望（"今天天气→怎么样/不错"）。
